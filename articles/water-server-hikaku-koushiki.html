ウォーターサーバーの選び方

ウォーターサーバーの料金・契約条件を公式サイトで比較｜PREMIUM WATER・フレシャス・ハミングウォーター

公開日: 2026-11-06 / 更新日: 2026-11-06

ウォーターサーバーは、月額の数字だけでは比べにくいサービスです。最低利用期間、解約するときの費用、手数料、配送の条件で、実際の負担が変わります。PREMIUM WATER・フレシャス・ハミングウォーターの3社を、各社の公式サイトで確認できた範囲で、条件をつけて並べました。

本記事はアフィリエイト広告（PR）を利用しています。

この記事の調査方法について 3社の公式サイト(料金ページ・よくある質問・規約)を2026年11月6日に実際に開き、載っている内容だけを引用しています。金額はすべて税込で、各社の表記どおりです(「不課税」と書かれているものはそのまま記載しています)。どれがおすすめかの判断はしていません。キャンペーンは短い期間で内容が変わるため、この記事には載せていません。編集部が実際に契約して使った記事ではありません。電気代の目安は、各社が公式サイトに書いている算出条件つきの数値で、使い方で変わります。

先に、3社の違いが出やすいポイントを表にまとめます(2026-11-06 時点・各社公式サイトの表記)。

PREMIUM WATER: 契約の種類・サーバー・申込日で費用が変わる

  • プラン → 「もっとPREMIUM」(最低5年)、「ずっとPREMIUM」(最低3年)のほか、2026年10月28日にpitapというサーバーと、7.2Lボトルのプランの受け付けが始まったと、公式のお知らせにあります。7.2Lプランは、3本1セットで税込4,989円、2本1セットで税込3,650円(4週に1回の定期配送の場合)です。「ご契約中に天然水1セットの本数を切り替えることはできません」と記載があります。
  • サーバー別の月額(もっとPREMIUM) → amadanaスタンダード 税込4,082円(レンタル無料)、famfit2・スリムサーバー4 税込4,190円(レンタル無料)、AURA・amadanaグランデ 税込4,410円(水4,190円+レンタル220円)。
  • 契約解除料 → 「もっとPREMIUM」(2026-01-15以降の申込)の例は、amadanaスタンダードが45,000円→35,000円→25,000円→15,000円→5,000円、スリムサーバー4・famfit2・AURA・amadanaグランデが50,000円→40,000円→30,000円→20,000円→10,000円と、利用年数に応じて5段階で下がります(それぞれ別のよくある質問のページの表)。「契約解除料は不課税です」と記載されています。申込日が違う場合や、他のプランは、金額が異なります(公式のよくある質問で確認してください)。
  • 返却 → 解約日から30日以内にサーバーの返却が確認できない場合は、製品補償料 税込33,000円と記載されています。
  • 水 → ナチュラルミネラルウォーター(非加熱処理・軟水)。「水源のご指定はできません。」「水源を変更させていただく場合がございます」とあります。

フレシャス: サーバーのレンタル料と、休止の条件

  • レンタル料 → 「すべてのウォーターサーバーでレンタル料 初月無料0円！2ヶ月目以降は前月のご使用量に応じて条件付きで無料」。Slat 税込990円(前月3箱以上で無料)、Slat+cafe 税込1,320円(3箱以上)、dewo ii 税込550円(2箱以上)、dewo mini 税込550円(3箱以上)。「1箱」の量はサーバーで異なり、たとえばSlatは9.3L×2本、dewo iiは7.2L×4パックです。
  • 水 → ナチュラルミネラルウォーター。FRECIOUS富士は、7.2Lパック 税込1,248円、9.3Lボトル 税込1,627円、4.7Lパック 税込999円。1回の配送は1箱単位です。
  • 解約金・交換 → レンタルプランで契約後またはサーバー交換後3年未満で終了した場合、サーバー1台あたり40,000円(不課税)。サーバー交換手数料は、1年以内 税込14,300円、1〜2年 税込8,800円、2年以上 税込5,500円です。
  • 休止 → 「ノルマはございません。原則は定期配送」。2ヶ月連続でお水の受け取りがないと、翌月以降、休止手数料 税込1,100円(月額。サービスを再開するまで)がかかります。

フレシャスの最新の料金・条件は公式サイトで確認できます: 富士の天然水ウォーターサーバー【フレシャス】

ハミングウォーター: ボトルではなく、水道水を使うタイプ

  • 方式 → 公式サイトでは「水道水の浄水型ウォーターサーバー(水道水補充型)」と書かれていて、給水タンクのお水は「3日ごとに入れ替えをお願いしております」とあります。タンクに水道水を補充して使うため、ボトルのお水は届きません。
  • 費用 → 月額 税込3,410円(レンタル料込み)。初回出荷手数料 税込2,200円。限定カラーは、初回に限定カラー料金 税込2,200円が別にかかります(公式の料金ページ)。
  • 容量 → flowsは約300L/月(1日約10L)、cotorisは約135L/月(1日約4.5L)。フィルターは8ヶ月ごとに届きます。
  • 解約 → 規定利用期間は2年。2年未満で終了するとサーバー引取手数料 税込33,000円。同じ機種への交換は税込9,900円です。月額は日割り返金なし(「翌月分の月額利用料がかかります」)と記載があります。

申し込む前の確認リスト(編集部の提案)

  • 最低利用期間と解約時の費用 → 引っ越し・使わなくなったときの費用の金額を、申込日・サーバーの種類ごとに確認する
  • お水を受け取らない月 → 休止できる期間と、休止の手数料を確認する
  • レンタル料が無料になる条件 → 「前月の使用量」などの条件が付いていないか確認する
  • 配送エリア → 沖縄・離島、住んでいる地域が対象か確認する
  • 電気代の目安 → 算出条件(使う水の量・単価・エコモード)を見て、自分の使い方に近いか確認する

まとめ

3社を公式サイトで並べると、月額の見え方の裏で、最低利用期間・解約時の費用・休止の条件・配送エリアに違いがありました。とくにPREMIUM WATERは、契約の種類・サーバー・申込日で契約解除料が変わるため、申し込み前に公式のよくある質問で金額を確認してください。どのサービスがよいかは、使う水の量と、住んでいる地域・暮らし方で変わります。

よくある質問

ウォーターサーバーを途中で解約すると、費用はかかりますか？

公式サイトでは(2026年11月6日時点)、3社とも、最低利用期間内の解約には費用がかかると記載されています。PREMIUM WATERは契約の種類・サーバー・申込日により、契約解除料が異なります(たとえば「もっとPREMIUM」は45,000円または50,000円から、利用年数に応じて段階的に下がるなど)。フレシャスはレンタルプランで3年未満の場合、サーバー1台あたり40,000円(不課税)です。ハミングウォーターは規定利用期間の2年未満の場合、サーバー引取手数料として税込33,000円です。

ハミングウォーターは、ボトルのお水が届くサービスですか？

いいえ。公式サイトでは、水道水の浄水型ウォーターサーバー(水道水補充型)と記載されています。給水タンクに水道水を補充して使い、届くのはフィルターです。
