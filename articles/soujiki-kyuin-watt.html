掃除機の吸引力はワット数で比べられる？消費電力と吸込仕事率の違い

公開日: 2026-10-29 / 更新日: 2026-10-29

本記事はアフィリエイト広告（PR）を利用しています。

この記事の調査方法について JIS C 9108(電気掃除機の性能測定方法)の定義、メーカー公式の仕様ページの注記、家電の専門メディアの解説、消費者庁の資料をもとに、掃除機の「W」の読み方を整理した記事です。出典は各段落の下にまとめています。

掃除機を比べようとすると、仕様表に「W(ワット)」の数字がいくつも出てきます。「ワット数が大きいほうがよく吸うのでは」と考えがちですが、掃除機の「W」には意味の違う2つの数字があり、片方は吸引力を表す数字ではありません。この記事では、その違いと、コードレス掃除機で吸引力の数字が見当たらない理由、代わりに見るとよいポイントを整理します。

結論だけ先に知りたい方へ

消費電力

消費電力(W)は吸引力の指標ではない

消費電力は掃除機が使う電気の量です。吸い込む力の目安としてカタログに載るのは「吸込仕事率」という別の数値です。

吸込仕事率

吸込仕事率(W)も「目安」

風量と真空度から計算する、JISで決められた吸い込む力の目安です。ヘッドを付けずに空気だけで測るので、実際のごみの取れ方はヘッドや床材で変わります。

コードレス

コードレスは数字がないことが多い

JISの吸込仕事率は充電式を対象外にしています。コードレスは数字より、ヘッドの種類・運転時間・重さ・お手入れで比べるのが現実的です。

掃除機の「W」には2種類ある

同じ「W」でも、仕様表には消費電力と吸込仕事率の2つが別々に載っていることがあります。たとえばパナソニックのキャニスター掃除機 MC-SK15Aの仕様ページには、消費電力が「950～約300W」、吸込仕事率が「320W～約80W」と、別の項目として書かれています。

消費電力は、掃除機が動くときに使う電気の量です。吸い込む力の指標として決められた数字ではないため、消費電力の大小で吸引力を比べるのは適切ではありません。吸い込む力の目安として使われるのは、もう一方の吸込仕事率です。

出典: パナソニック公式 MC-SK15A 仕様ページ

吸込仕事率とは — 測り方と限界

吸込仕事率は、JIS C 9108で「掃除機の空気を吸い込む能力を表す指標」とされ、風量(1分あたりに吸い込む空気の量)と真空度(吸い込む圧力)を掛け合わせて計算します。カタログには、その最大値が載ります。パナソニックも仕様ページで「吸込仕事率とは、JIS規格に定められている吸込力の目安」と説明しています。

注意したいのは測り方です。吸込仕事率は、床用ヘッド(先端のノズル)を付けない状態で、空気だけを吸い込んで測ります。実際にごみを吸わせて測っているわけではありません。そのためパナソニックは「使用時の吸塵力は吸込仕事率以外に吸込具の種類･ゴミのたまり具合や床材の違いなどによって異なります」と注記しています。吸込仕事率が低めでも、ごみを取りやすいヘッドを採用していれば、実際の掃除ではよく取れることがある、という解説もあります。

出典: JIS C 9108:2017(電気掃除機の性能測定方法)、パナソニック公式 MC-SK15A 仕様ページ、家電Watch「吸込仕事率」(2008年)、@DIME(2021年7月)

コードレス掃除機で数字が見当たらない理由

吸込仕事率を定めたJIS C 9108は、対象を定格消費電力100～1,500Wの家庭用掃除機とし、充電式掃除機を対象から外しています。実際、スティックタイプのコードレス掃除機で吸込仕事率が書かれている例は珍しい、と紹介されています。書かれている製品もありますが、JISの対象外のため、測り方がJISと同じとは確認できません。コード付きの掃除機の数字と並べて比べるのは避けたほうが安全です。

ロボット掃除機では、吸引力を「Pa(パスカル)」で書く製品もあります。Paは吸い込む圧力(真空度)だけを表す単位で、吸込仕事率のように風量は含みません。ロボット掃除機メーカーのECOVACSも、Paだけで性能の良し悪しは決まらず、風量も関係すると説明しています。また、「AW(エアワット)」という単位を使うメーカーもあります。AWの測り方はメーカーが示す条件によるため、吸込仕事率と同じ物差しかどうかは数字だけでは分かりません。

出典: JIS C 9108:2017、@DIME(2021年7月)、ECOVACS公式ブログ(2024年9月)

代わりに何を見て比べればいいか

吸い込む力を数字だけで比べにくい以上、コードレス掃除機は次のような比べられる仕様で選ぶのが現実的です。当サイトのコードレス掃除機の比較記事でも、同じ理由で吸引力は点数に入れず、これらの項目で比べています。

  • 床用ヘッドの種類: モーターでブラシを回すヘッドか、フローリング向けのヘッドか、など。ごみの取れ方はヘッドによっても変わります。
  • 運転時間: 1回の充電で使える時間。モードによって変わるため、モードごとの時間を確認します。
  • 重さ: 毎日出し入れするなら、ヘッドやパイプを付けた標準の状態での重さを比べます。
  • お手入れ: ダストカップやフィルターが水洗いできるか、紙パック式かサイクロン式か(紙パック式とサイクロン式の比較)。

なお、広告で「吸引力No.1」のような表示を見かけることがあります。消費者庁は、No.1表示は合理的な根拠に基づいている必要があり、根拠がなく事実と異なれば不当表示として問題になる、としています。何と比べて、どんな条件で1位なのかが書かれているかを確かめると安心です。

出典: 消費者庁「No.1表示に関する実態調査について」(2024年9月)

よくある質問

消費電力が大きい掃除機ほど、よく吸いますか？

消費電力は掃除機が使う電気の量で、吸引力そのものではありません。吸い込む力の目安としてカタログに載るのは「吸込仕事率」という別の数値です。

吸込仕事率が大きければ、ごみがよく取れますか？

目安にはなりますが、それだけでは決まりません。吸込仕事率は床用ヘッドを付けない状態で、空気だけで測る数値です。メーカー自身も、使うときの吸い取る力はヘッドの種類やごみのたまり具合、床材によって変わると注意書きしています。

コードレス掃除機の仕様に吸込仕事率が見当たらないのはなぜですか？

吸込仕事率を定めたJIS(JIS C 9108)は、対象から充電式掃除機を外しています。スティックタイプのコードレス掃除機で吸込仕事率が書かれている例は珍しく、書かれていても、JISの対象外のため測り方がJISと同じとは確認できません。

「Pa(パスカル)」や「AW(エアワット)」と吸込仕事率は比べられますか？

そのままは比べられません。Paは吸い込む圧力(真空度)だけを表す単位で、吸込仕事率は風量と真空度を掛け合わせた数値です。AW(エアワット)を使うメーカーもありますが、その測り方はメーカーが示す条件によるため、吸込仕事率と同じ物差しかどうかは数字だけでは分かりません。

「吸引力No.1」と書かれた製品はどう見ればいいですか？

消費者庁は、No.1表示は合理的な根拠に基づいている必要があり、根拠がなく事実と異なれば不当表示として問題になる、としています。何と比べて、どんな条件で1位なのかが書かれているかを確かめると安心です。
