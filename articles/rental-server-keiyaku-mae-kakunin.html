レンタルサーバーの料金表の見方｜契約前に確認したいこと(エックスサーバーの料金表で確認)

公開日: 2026-11-07 / 更新日: 2026-11-07

ブログやサイトを始めるときは、まずレンタルサーバーを契約することになります。月額の数字だけで決めると、初期費用や契約期間の条件を見落としがちです。エックスサーバーの公式の料金表と公式ページで確認できた範囲で、契約前に見ておきたい点を整理しました。

本記事はアフィリエイト広告（PR）を利用しています。

この記事の調査方法について エックスサーバーの公式サイトの「料金プラン比較」ページ、「よくある質問」、マニュアルを2026年11月6日に実際に開き、載っている内容だけを引用しています。料金は税込で、公式の料金表の値です。キャンペーンなどで、申し込み時の金額が変わる場合があります(公式の料金表の注記に、キャンペーン適用外の見積書を希望する場合はサポートへ連絡する、という案内があります)。編集部がレンタルサーバーを実際に契約して使った記事ではなく、他社のサーバーとの比較もしていません。

確認したのは、初期費用・契約期間と支払い方法・独自ドメインとSSL・無料お試しの4点です(あわせて、プランごとのディスク容量も載せています)。いずれも、他のレンタルサーバーを選ぶときにも見ておきたい項目です。

初期費用: 料金表では0円

エックスサーバーの公式の料金表(税込)では、スタンダード・プレミアム・ビジネスのいずれも、初期費用は0円と記載されています。

契約期間と支払い方法: 長いほど月額換算は安く、支払いは一括前払い

公式の料金表では、契約期間(3・6・12・24・36ヶ月)ごとに、月額料金が次のように記載されています(税込)。

📋

「お支払いはご契約期間分の一括前払いとなります。」
出典: エックスサーバー「料金プラン比較」の料金表の注記(2026-11-06 閲覧)

たとえばスタンダードを、月額×月数の単純計算で見ると、12ヶ月で13,200円(1,100円×12)、36ヶ月で35,640円(990円×36)になります。月額に換算した金額は、契約期間が長いほど低く見えますが、支払いは契約期間分をまとめて前払いする形です。実際に請求される金額は、申し込み画面の見積りで確認してください。

独自ドメインとSSL: 特典と、無料のSSL

同じ公式ページには、次のように書かれています。

  • 独自ドメイン永久無料特典 → 「独自ドメインを2つ無料でプレゼント」。「プレゼントされたドメインは契約期間中の間ずっと無料」とされています。選べるドメインの種類はプランで異なり、スタンダードは11種類(.com / .net / .org など)、プレミアムは12種類、ビジネスは16種類です。「新規取得には取得条件があります」と注記があります。
  • 無料独自SSL → 「当サーバーで運営中のドメインに対して無料・無制限で独自SSLを利用することが可能です」と記載されています。
  • ディスク容量 → スタンダード 500GB(NVMe)、プレミアム 600GB(NVMe)、ビジネス 700GB(NVMe)。

無料お試し: 10日間。ただし、条件があります

公式のよくある質問には、次のように書かれています。

📋

「お申し込み後10日間がお試し期間となります。」「メールアカウントの作成、サーバープログラム(CGI/PHP等)によるメール送受信、追加FTPアカウントの作成などが制限されていますが、ほぼ正式なサーバーと同様の機能をお使いいただくことができます。」「お試し期間中、お支払手続きを行われますと、本契約となり上記機能がすぐにご利用いただけます。」
出典: エックスサーバー「お試し期間の詳細について教えてください。」(2026-11-06 閲覧)

注意したいのは、「WordPressクイックスタート」を使って申し込む場合です。公式のよくある質問には、「お申し込みと同時にサーバー料金のお支払いが発生します」「10日間無料のお試し期間はありません」とあります(お支払方法はクレジットカード払い・あと払い(ペイディ)のみ)。無料お試しを使いたいときは、この機能を使わずに申し込む必要があります。

💡

公式のマニュアルには、お試し期間でそのまま使い続けても問題ないと思ったら、ご利用料金を支払う、「お支払いの確認が取れ次第、本契約へと移行します」とあります。お試し期間中に設置したプログラムやアップロードしたデータは、本契約への移行後もそのまま使えるとされています。

申し込む前の確認リスト

  • 初期費用の有無 → 料金表の初期費用欄を確認する(エックスサーバーは0円)
  • 契約期間と支払い方法 → 月額換算が安い長期契約は、一括前払い。必要な期間を考えて選ぶ
  • 独自ドメイン・SSLの扱い → 取得条件、契約期間中だけ無料かなどを確認する
  • 無料お試しの条件 → 制限される機能と、クイックスタートでは使えない点を確認する

ここまでは、エックスサーバーの公式ページで確認した内容です。他のレンタルサーバーを検討する場合も、同じ項目を各社の料金ページで見比べると、条件の違いが分かります。

よくある質問

エックスサーバーの初期費用はいくらですか？

公式の料金表(税込)では、スタンダード・プレミアム・ビジネスのいずれも初期費用は0円と記載されています。お支払いは契約期間分の一括前払いです。

エックスサーバーの無料お試しはありますか？

公式のよくある質問には、お申し込み後10日間の無料お試し期間があると記載されています。お試し期間中は、メールアカウントの作成や追加FTPアカウントの作成などが制限されます。WordPressクイックスタートで申し込むと、10日間の無料お試し期間はなく、申し込みと同時に料金のお支払いが発生します。
