玄関の収納は「床に置く」か「壁を使う」か

公開日: 2026-09-25 / 更新日: 2026-09-25

玄関の収納を増やす方法は、大きく2つしかありません。床に物を置くか、壁の高さを使うかです。ここが決まらないまま製品を見比べると、迷い続けることになります。

本記事はAmazonアソシエイト・プログラムを含むアフィリエイトプログラムを利用して商品を紹介しています。

この記事の調査方法について 公的機関の公表資料とメーカーの公式情報をもとに整理した解説記事です。編集部が製品を購入して設置・試用した記事ではありません。引用した資料は末尾にすべて出典を記載しています。実機で検証した記事には、その旨を本文中に明記します。

玄関に物が増えてくると、「収納を足そう」と考えます。ところが検索すると、ベンチ、シューズラック、突っ張りラック、シューズボックスと、形の違うものが一度に出てきて、どれを見ればいいのか分からなくなります。

先に決めるべきなのは、製品ではなく場所です。玄関で使える空間は「床」と「壁」の2つしかなく、どちらを使うかで候補がきれいに分かれます。ここを決めてから製品を見ると、比べる対象が一気に減ります。

  • 床を使うか壁を使うかで決める
  • 耐荷重の表示の読み方
  • 買う前に測る場所

床を使う：ベンチ型

玄関の床に置いて、座る場所と収納を同時に作るのがベンチ型です。座面の下が棚になっていて、よく履く靴をそこに入れる形が多くなっています。

向いているのは、靴を履くときの姿勢が困っている場合です。ブーツやひも靴を履くとき、小さな子どもの靴を履かせるとき、足腰に不安があるとき。壁の収納をいくら増やしても、この困りごとは解決しません。

代わりに失うのは床面積です。玄関は家の中でも特に狭い場所なので、幅の分だけ通り道が細くなります。扉の開く向きとぶつからないかも確認が要ります。

製品ごとの幅・奥行き・座面の耐荷重・素材の違いは、玄関収納ベンチ比較、耐荷重と収納量で選ぶ基準で4製品を並べて比べています。

壁を使う：突っ張り型

床と天井の間に柱を立てて、その柱に棚やフックを付けるのが突っ張り型です。床にほとんど場所を取らずに、高さ方向をまるごと使えます。

向いているのは、床は足りているのに置き場所が足りない場合です。傘、コート、帽子、宅配の荷物、子どもの外遊び道具。床に置くと散らかって見えるものを、視線より上に逃がせます。賃貸で壁に穴を開けられない場合にも選ばれます。

代わりに必要になるのが天井の条件です。ここは次の章でまとめて扱います。

対応する高さ・耐荷重・穴あけの要否といった製品ごとの違いは、玄関の突っ張りラック比較、天井の高さと耐荷重で選ぶ基準で比べています。

どちらを選ぶか、3つの質問で決まります
1. 靴を履くときに座りたい？はい → ベンチ型。これは壁の収納では解決しません
→
2. 床の通り道に余裕はある？いいえ → 突っ張り型。床を減らさずに済みます
→
3. 天井は平らで、高さが分かっている？いいえ → 突っ張り型は避ける。次の章の理由です

両方を同時に置くのは、最初の一手としては勧めません。床面積が減ったうえに、上にも物が増えて圧迫感が出ます。どちらか一方で足りるかを見てから、もう一方を足すほうが失敗しにくくなります。

突っ張り型を選ぶ前に、天井を見る

突っ張り型は「置くだけ」に見えますが、実際は天井と床で挟んで支えているので、天井の状態に性能が左右されます。

突っ張り製品を出している平安伸銅工業は、公式サイトで次のように案内しています。

⚠

「天井に傾斜や凹凸のあるところには取付できませんので、ご注意ください。」
あて板を使う場合は「あて板の厚みは15mm以上のものをご用意ください。」
設置後は「定期的に点検し、ゆるみがないことを確認してください。」
出典: 平安伸銅工業 公式サイト「突っ張り棒で地震対策！耐震ポールを正しく使って、家具の転倒を防ごう」（2026-09-24 閲覧）

玄関は、天井に点検口があったり、段差がついていたり、照明が出っ張っていたりすることが少なくない場所です。買う前に見上げて、柱を立てたい位置の天井が平らかどうかを確かめてください。

同社は、家具の転倒防止として使う場合の取り付け位置を「家具の両端 ＆ 壁に近い奥側に取りつける。」とも案内しています。これは玄関ラックの話ではありませんが、突っ張り製品は置く位置で効き方が変わるという点は共通します。

「耐荷重30kg」は、30kgまで安全という意味ではない

ベンチの座面にも、突っ張りラックの棚にも、耐荷重の数字が書いてあります。この数字は条件つきの上限で、その数値まで安全に使えるという保証ではありません。

国民生活センターは2016年11月10日、スチール製のキャスター付ラックについての試験結果を公表しています。

📋

「適正な締付けトルク（4.0N・m）で上段の荷重を増加していくと40kgまでは支柱はほぼ傾きませんでしたが、50kgで1°程度傾き」
同センターは「耐荷重の表示を変更する、強度を上げるなどの改善が望まれました」としています。その後メーカーは表示を「最大80kg」に変更し、ボルトの締め方を説明書に追記しました。
出典: 国民生活センター「表示された耐荷重以下でも支柱が傾いたスチール製のラック（相談解決のためのテストからNo.102）」2016年11月10日公表（2026-09-24 閲覧）

この試験の対象は、玄関ベンチでも突っ張りラックでもありません。キャスター付きのスチールラックについての事例です。それでも読み取っておく価値があるのは、耐荷重の数字は組み立て方や使い方を含んだ条件の上で成り立っているという点です。ボルトの締め方ひとつで結果が変わっています。

実際の選び方としては、載せたい重さの分だけ余裕を見るのが素直です。体重70kgの人が座るベンチなら、耐荷重70kgちょうどではなく、もう一段上を見る。棚に置きたい物が10kgなら、20kgの棚を選ぶ。数字を使い切らない、という考え方です。

買う前に測る3か所

玄関は寸法の個体差が大きい場所です。次の3つは、製品を見る前に測っておくと候補が絞れます。

  • 床から天井までの高さ
    突っ張り型は対応範囲が決まっています
  • 置きたい場所の幅と奥行き
    扉が開く範囲とぶつからないか
  • 通り道に残る幅
    置いたあと人がすれ違えるか

3つめは忘れられがちですが、あとから一番効いてきます。玄関は毎日通る場所なので、10cm狭くなるだけで体感が変わります。

まとめ

玄関の収納は、床を使うか壁を使うかを先に決めると、見るべき製品が半分になります。

  • 座る場所が欲しい → ベンチ型。壁の収納では解決しない
  • 床を減らしたくない → 突っ張り型。ただし天井の条件を先に確認
  • 耐荷重は使い切らない → 数字は条件つきの上限

製品ごとの違いは、それぞれの比較記事にまとめています。玄関収納ベンチ比較と玄関の突っ張りラック比較をあわせてご覧ください。
